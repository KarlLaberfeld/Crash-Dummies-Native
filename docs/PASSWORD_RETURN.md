# Complete password/title returns and music-test presentation

October 20, 2026. Continues all seventeen
[validation/feedback cases](PASSWORD_EDIT_FEEDBACK.md) in both retained histories.
Start reaches the complete page-zero menu, A/B reaches fresh password input,
and the tenth valid password reaches the complete initial music-test screen.
The corresponding boundaries are 2bdc..2707, 2bdc..2ba7 and 2d65..2dab.

All 34 comparisons match 8,950 boundaries, 2,814 display/music services,
11,094 vectors, 16,560 raster boundaries, 88,972 polls, 63,612 stores,
69,632 direct map bytes, 8,704 shadow-object bytes and 16,884 voice rows,
**zero differences**. Each case preserves all 403 / 407 preceding complete
native CSVs. Batches fully qualify shared ancestors once and independently
prove each child prefix and new original controls. Each append-only extension
preserves two unobserved prefix/full hash repetitions and observed agreement.

The typed native feedback state chooses the destination. All closing waits,
duplicate clears, static data, safe stores and reopening waits are independent
native work. Title return performs its counter wait and song-1 reset, installs
the complete ten-row page-zero rectangle and initializes the 480-update menu
loop. Password return starts song 7 and clears the cursor/eight digits. Test
presentation writes all 42 glyphs in three rows, remains silent and initializes
tune/effect/last-tune to 0/0/255. Start selections survive all returns.

The existing page-zero composer can explicitly inherit this qualified caller's
clock. Its normal fixed-entry guard remains unchanged; retained callers still
require complete closing state, valid geometry, future deadlines, countdown,
song and empty objects. No source state, clocks, schedules or fitted allowances
initialize execution. Original ROM/data/recordings/reference binaries stay local.

Two representation exclusions are explicit. First, disabled-driver song and
voice payloads remain recorded but are compared as logical silence, as in the
preceding feedback scope. Enabled songs/voices are never masked. Second, after
title rectangle dispatch the original FF9b no longer represents a password
cursor: 21f6 uses it for the source-pointer low byte and 22e4 uses it for the
data bank. The native page owns decoded maps and writer coordinates rather
than that raw bank scratch. Raw FF9b observations remain recorded; this field
alone is excluded from title rectangle entry onward and at the title summary.
Active password and music-test cursors remain compared. Test selector fields
are compared only for the test destination. These exclusions do not mask map,
time, raster, active input or selection differences.

Use `tools/password_return_reference.py prepare/capture/compare`, extending
the accepted feedback control by 100 host frames. Capture takes `ROM --capture
ACCEPTED_FEEDBACK_CONTROL --control RETURN_CONTROL --parent-out FEEDBACK_REFERENCE
--out RETURN_REFERENCE`. Replay the complete independent native chain with
`--password-return` and the full raw display input stream. Compare inherits
the feedback arguments plus `--return-screen-out`, `--return-screen-control`
and `--feedback-base`. `compare-batch MANIFEST` accepts a local JSON list of
argument-path dictionaries sharing one ancestry. CSVs use `.fifth.password-return*`;
reports use `.password-return.comparison.json`.

native return assertions and 1,400 Python tests, including 31 new provenance,
destination, storage, reset, batch and narrow scratch-projection integrity cases.
