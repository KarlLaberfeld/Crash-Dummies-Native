and this observation's complete control endpoint are the same. The final memory
fingerprint is read once and checked against the previously repeated unobserved
control hashes. Reading the entire CPU-style memory view twice at one boundary
is not an additional independent replay. An isolated uninstrumented check kept
the CPU cycle unchanged across three views: the first matched the accepted

and the third equalled the second. No other addresses differed. An initial
double-read rejection is retained only
as a local failed observer attempt and is not acceptance or a native allowance.
